# 🌊 养令 YangLing

> **懂中国人身体节律的 AI 养生搭子**
> 说一句话 → 结合节气·时辰·体质 → 生成「今日养生时序卡」——一杯、一动、一息,每天 3 分钟。

**复客松 · 华润三九杯 AI 医疗健康黑客松**(2026.9.10–13)参赛作品 · 主攻 A3 现代养生 · 兼攻 A1 银发家庭守护

---

## ✨ 这是什么

把「今天不知道怎么养生」变成一张**现在就能照着做**的行动卡。

```
输入状态 → 安全识别 → 规则引擎生成 一杯/一动/一息 → 打卡 → 给爸妈版
```

- **说状态**:用自然语言描述今天的感受(「昨晚3点睡,嘴苦,下午要讲一下午会」)
- **得时令方案**:结合二十四节气、十二时辰、九种体质,生成按时辰排布的干预卡
- **养成立**:打卡即完成,养生日历记录真实进度;一键切换「给爸妈版」大字卡片

**差异化**:
- 不是 AI 舌诊/问诊,也不做诊断——只做**生活方式建议**,合规安全
- 结构化「节气×时辰×体质」知识库**规则兜底**,医学可审、不会胡说
- LLM 只负责抽取与表达,决策交给规则引擎
- **东方美学仪式感**:墨夜金线视觉 + 呼吸流体背景 + 时辰罗盘

## 🏗 架构

```
src/
├── core/
│   ├── contracts/validate.js   # Schema S/I/P/K 运行时校验
│   ├── safety/index.js         # 红旗症状拦截 + 特殊人群提示
│   ├── engine/                 # 规则引擎:节气×时辰×体质×状态 → 干预
│   │   ├── index.js            #   匹配 + fallback 链
│   │   └── knowledge.json      #   知识库(医学可审)
│   ├── llm/client.js           # 状态抽取(关键词 + 预留真 LLM)
│   ├── profile/store.js        # localStorage 画像(方案/打卡分离)
│   ├── demo/states.js          # 4 个预置演示场景
│   └── motion/
│       ├── pose-engine.js      # 动作-关键点-达标角度契约(mock)
│       ├── pose-detector.js    # MediaPipe PoseLandmarker 封装
│       └── camera.js           # getUserMedia 封装(纯本地)
├── ui/
│   ├── pages/                  # 6 个页面
│   └── motion/PoseGuide.jsx    # 动作跟随:摄像头预览+骨架叠加
└── theme/                      # 墨夜金线设计 tokens + 呼吸背景
```

### 数据流(主链路)

```
自然语言 → extractState(关键词+风险检查) → 状态 JSON
  → runEngine(规则匹配+安全门禁) → 干预 JSON
  → 时序卡渲染(一杯/一动/一息) → 打卡 → profile(checkins)
```

### 摄像头(纯本地,不上传)

```
本地视频帧 → MediaPipe PoseLandmarker → 33 关键点
  → 骨架叠加(canvas)→ 关节角度 → estimatePose → 达标判定
```

- 授权后才启动,画面**只在本机浏览器处理,零上传**
- 需 localhost 或 HTTPS
- 模型走 CDN(约 5MB);加载失败自动回退手动完成,不阻塞演示
- wasm 已本地化到 `public/mediapipe-wasm/`

## 🛡 安全与合规

- **红旗症状拦截**:胸痛、呼吸困难、持续高热等 → 只出就医提示,不生成干预(100% 测试覆盖)
- **特殊人群提示**:孕期、慢病、服药、过敏 → 提示谨慎咨询专业
- **不做诊断**:体质表述为「可能倾向/自我描述标签」,非确诊
- **免责声明**:所有方案附"生活方式建议,不替代专业诊疗"
- **隐私本地化**:画像存 localStorage,可一键清除,不上传
- **医学审核**:知识库需医学成员校验(`knowledge.json` 内容来源见 `docs/`)
