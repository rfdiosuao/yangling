# 🏗 养令 YangLing · 系统架构

> **复客松 · 华润三九杯 AI 医疗健康黑客松**(2026.9.10–13)
> 主攻 A3 现代养生 · 兼攻 A1 银发家庭守护
> 本文档为团队开发的**单一事实来源**,所有模块按此实现。

---

## 0. 设计原则

1. **规则兜底,LLM 表达**:专业结论由结构化规则引擎产出(医学可审、不会胡说),LLM 只做个性化表达——从架构上规避"AI 乱给医疗建议"。
2. **本地优先**:画像存 localStorage,无后端、断网可演示(黑客松保命)。
3. **预置数据兜底**:全程预置 demo 数据 + 录屏,网络/模型失败也能演。
4. **东方美学统一**:米白宣纸底 + 墨色 + 随节气变的主色 + 流体呼吸背景(复用 02-assets 蒸馏)。
5. **契约先行**:模块间通过冻结的 JSON schema 通信,靠 mock 数据并行开发。

## 5. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | React 18 + Vite | 团队熟悉、秒级 HMR、零配置 |
| 路由 | react-router-dom | 多页面(对话/时序卡/日历/家庭) |
| 状态 | 原生 + Context | 轻量,不引入 Redux 复杂度 |
| 样式 | CSS Modules + tokens.css | 设计系统集中管理 |
| LLM | StepFun/MiniMax/百川(赛事 token) | 零成本,资源方评委加分 |
| 画像 | localStorage | 无后端,断网可演示 |
| 部署 | GitHub Pages / 任意静态托管 | 提交"可访问链接" |

## 6. 稳定性兜底(黑客松保命)

1. **LLM 不可用** → 规则引擎直接输出(无需 LLM 也能演示主链路)
2. **LLM 输出非法 JSON** → 固定 schema + 重试 1 次 + 回退规则模板文案
3. **网络失败** → 预置 demo 数据 + 录屏双保险
4. **3D/重渲染跑不动** → 自动降级为 2.5D/静态(复用 worldseed 探针思路)
