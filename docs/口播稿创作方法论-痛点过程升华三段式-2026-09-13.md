# 养令 · 口播稿创作方法论：痛点 → 过程 → 升华（三段式 SOP）

2026-09-13 立 · 适用：黑客松路演视频配音稿、现场宣讲稿、Demo 解说稿

> **以后团队出任何口播稿，一律按本方法论的骨架写。**
> 它不是某一篇稿子，而是写稿的"模具"：先套骨架，再填内容。
> 范例稿见 [`现场路演讲稿-2026-09-13.md`](现场路演讲稿-2026-09-13.md) 与《演示视频口播稿-利他版》v14。

---

## 0. 理论来源：把高考作文那套搬过来

评委听路演，和阅卷老师看作文是一回事：**前 30 秒定档，结构清晰的赢，东一榔头西一棒子的输。**
高考作文能拿高分的技巧，几乎可以一对一搬过来：

| 高考作文技法 | 对应到口播稿 | 回答的问题 |
|---|---|---|
| **凤头**（开头要漂亮、破题快） | **第一段 · 痛点** | 这是个真问题吗？跟我有关吗？ |
| **猪肚**（中间内容充实、条理清楚） | **第二段 · 使用过程（功能）** | 你怎么解决？我怎么用？真的能用吗？ |
| **豹尾**（结尾有力、余味长） | **第三段 · 升华** | 你做这件事的意义是什么？我记住了什么？ |
| 议论文三段论：提出问题—分析问题—解决问题 | 痛点（提出）→ 过程（解决）→ 升华（回收+拔高） | 全篇逻辑链 |
| 起承转合 | 痛点起 → 理念承 → 演示转（含家庭线、底线）→ 升华合 | 四段式节奏 |
| 以小见大 | 从"一句我没事/一颗枸杞"的生活切片，讲到健康服务千人千面 | 切入点选择 |
| 首尾呼应 | 开头"我没事只能靠猜" → 结尾"不再只能靠猜" | 闭环感 |
| 事实论证 + 道理论证 | 问卷数据 + 赛题原话引用 + 医学博士把关 | 可信度 |
| 对比论证 | 千人一面（所有人同一张卡） vs 千人千面（四种体质四套方案） | 差异化 |
| 感情真挚、思想健康 | 真实经历、温柔语气、不越界诊断 | 合规底线 |
| 审题扣题 | 赛题关键词必须在稿中"响"（千人千面、银发守护） | 扣题分 |
| 线索贯穿 | 一个意象走到底（养令=小芽/小铃铛；温度线 凉→暖→更暖） | 记忆点 |

**一句话记住：凤头抛痛点，猪肚演过程，豹尾收价值。**

---

## 1. 总骨架与配比

| 段 | 名称 | 占比（4 分钟稿） | 字数（约 900 字） | 必答问题 |
|---|---|---|---|---|
| 一 | **痛点**（凤头） | 20%–25%（0:00–1:00） | 180–220 字 | 谁在痛？痛在哪？有多普遍？ |
| 二 | **过程**（猪肚） | 55%–60%（1:00–3:20） | 500–550 字 | 怎么解决？怎么操作？边界和下一步？ |
| 三 | **升华**（豹尾） | 18%–20%（3:20–4:00） | 160–180 字 | 解决了之后，世界好在哪？金句是什么？ |

> 配比可以 ±5%，但**三段的顺序永远不能换，任何一段不能省**。
> 3 分钟稿按 0.25 / 0.55 / 0.20 压缩；5 分钟稿把第二段功能演示扩到 65%。

---

## 2. 第一段 · 凤头 = 痛点（前 1/4 时间）

### 2.1 这一段要走完的五步（按顺序）

1. **设问/场景开场**——不寒暄、不自报家门式堆砌，第一句话就把听众拉进画面。
   - 句式："你有多久，没……了？" / "你有没有发现……"
2. **白描一个生活切片**（以小见大）——具体人物 + 具体动作，忌形容词堆砌。
   - 养令实例：爸妈总说"我没事" / 深夜刷完手机往保温杯丢枸杞 / 闹钟响了翻身按掉。
3. **引用赛题原话破题**（审题扣题 + 借权威）。
   - 养令实例："一边熬夜一边泡脚"——赛题发布会。
4. **甩数据**（事实论证，最多 3–4 个，百分比优先于样本绝对值）。
   - 养令实例：41 份问卷 → 43.9% 坚持不下来 / 56.1% 忙起来就忘 / 36.6% 没人纠正 / 70.7% 要依据。
5. **一句话亮中心论点**（议论文的"立论"）。
   - 句式："所以，我们做了 X：不是……，而是……。"
   - 养令实例："所以我们做了养令：不是再给你一篇文章，而是把今天该做什么、怎么做、做得怎么样，直接摆到你面前。"

### 2.2 雷区

- ❌ 开头先讲团队、讲愿景、讲技术栈（评委还不知道你解决什么问题）。
- ❌ "随着社会发展、人们生活水平提高……"式空话开头。
- ❌ 数据超过 4 个，或念样本量却不报百分比。
- ❌ 痛点和后面的功能对不上（开头说 A 痛，中间全在演示 B）。

---

## 3. 第二段 · 猪肚 = 使用过程（中间 6 成时间，全篇得分段）

### 3.1 内部节奏：承 → 转（演示）→ 守（边界）

**① 承 · 一句话理念 + 对比论证（约 25 秒）**
- 先用赛题的问题接棒："能不能从千人一面，变成千人千面？"
- 立刻给答案，且用**对比**让差异肉眼可见：
  过去/别人 = 十个人同一张卡；我们 = 同一句输入 × 四种体质 = 四套方案（阴虚麦冬/阳虚桂圆/气虚黄芪/湿热薏米）。
- 句式："不是……，而是……。"

**② 转 · 分镜式操作流："三步带你用一遍"（约 70–90 秒，最重头）**
- 严格按**用户操作的时间顺序**写（说明文的程序顺序），第一步、第二步、第三步，评委脑子里能跟着点。
- 每一个功能点都用**功能三段式句式**：

  > **是什么**（功能名）→ **怎么用、屏幕上看到什么**（操作 + 画面）→ **解决第一段的哪个痛**（叙议结合，每段点一句就够）

  - 例 1：一杯一动一息 → 输入状态、点发送、三张卡滑出、每张标来源 → 解决"不知道今天具体做什么"。
  - 例 2：摄像头纠正 → 授权、真人入镜、骨架点、练偏提示/练到位开花 → 解决"没人纠正"。
  - 例 3：呼吸 + 本机提醒 + 7/14/30 天小芽成长 → 解决"坚持不下来、忙起来就忘"。
- **诚实演示原则**：说"先授权再识别"这种真实步骤；规划中的功能（手表/手环）用"下一步"，绝不包装成已上线。

**③ 转 · 副赛道/情感功能（约 25 秒）**
- 家庭线沿用同一套句式：引用扣题（"父母想独立，子女想放心"）→ 怎么绑定、能看见什么 → 边界（双方同意、非病历非监控、随时解绑）。

**④ 守 · 底线与未来（约 20 秒，议论文的"论证严密性"）**
- 三条底线一口气讲清（数据有来源 / 本地识别不上传 / 没依据不装懂）+ 专业背书（在读医学博士研究生）。
- 未来硬件只说"下一步"：持续异常 → **提醒就医**，"不诊断、不处方、不替代检查"。
- 句式："X 负责……；医院负责……。"（责任划界，显得清醒可信）

### 3.2 详略原则（高考作文的"详略得当"）

- **核心闭环（输入→三卡片→摄像头→成长）详写**，每个动作给 2–4 秒画面停留；
- 技术架构、商业规划**略写**，一句话带过；
- 同一件事不重复抒情——车轱辘话是口播稿最大的字数杀手。

### 3.3 雷区

- ❌ 功能罗列成参数表（"我们有 A、B、C、D 功能"），没有操作流、没有画面。
- ❌ 只演示不回扣痛点（评委要听到"这治的是刚才哪个病"）。
- ❌ 把规划说成已上线；省略摄像头授权等真实步骤。
- ❌ 中间段占比不到一半——猪肚不充实，全篇立不住。

---

## 4. 第三段 · 豹尾 = 升华（最后 1/5 时间）

### 4.1 四步收束（按顺序）

1. **回收痛点**（首尾呼应）：把第一段抛的问题，用"三个具体问题"重新点一遍——今天该做什么 / 动作对不对 / 家人知不知道。**问题要和开头逐一对得上。**
2. **亮工作量与诚意**（可选，一句话）：4 人 / 10 天 / 0 预算 / 从零到线上可点。
3. **划界表态**（思想健康、反衬可信）："我们不替医生下结论，也不让家人互相监控。"
4. **金句定格**：从产品功能升到人的情感，slogan 短句收尾。
   - 公式：**具体动作/意象 + 情感结果**，不要空喊"大爱/感恩"。
   - 养令实例："让一句'我没事'，不再只能靠猜。" → "养令——练对、看见、有人惦记。"

### 4.2 金句怎么练

- 从开头埋的意象里收（开头"我没事"，结尾就还"我没事"）。
- 短句：8–14 字，能上墙、能做 PPT 封底。
- 先写 3 个备选，选最具体、最不像口号的那个。

### 4.3 雷区

- ❌ 结尾才开始讲新技术、新功能（豹尾不能塞新信息）。
- ❌ "谢谢聆听/感谢观看"式弱结尾，没有记忆句。
- ❌ 升华脱离产品喊口号（产品是养生陪伴，就别喊成科技改变人类）。

---

## 5. 贯穿全篇的三条暗线（写完必须回头检查）

1. **扣题线**：赛题关键词至少"响"三次——痛点段引一次、理念段点一次、副线段点一次（养令：千人千面 / 银发守护）。
2. **呼应线**：开头埋的钩子（"我没事"/凉了的茶），结尾必须回收。
3. **温度线**：情绪有弧线，不能一个调门到底（养令：凉 → 暖 → 更暖；音乐、画面色温跟着走）。

## 6. 空白模板（复制即用）

```markdown
# XX · 口播稿（痛点→过程→升华）

时长 X:00 · 约 XXX 字 · 配音/宣讲人：

## 一、痛点（0:00–0:XX，约 22%）
（设问开场，不寒暄）
> 你有多久/你有没有发现，______（具体人物 + 具体动作的生活切片）？
> 他们总说"______"，但______（矛盾点）。
> 你自己也一样：______（第二切片，最好引用赛题原话"______"）。
> 这不是缺______，是缺______（点破问题本质）。
> 我们的调研：N 份问卷，XX% ______、XX% ______、XX% ______（3–4 个）。
> 所以，我们做了 XX：不是______，而是______。（中心论点）

## 二、过程（0:XX–0:XX，约 58%）
### 2.1 理念（承，~25s）
> 赛题问："能不能从______变成______？"
> 我们的回答：过去/别人是______；我们是______（对比，最好四宫格可演示）。
> 不是______，而是______。

### 2.2 三步用一遍（转，重头）
> 第一步：______（操作 + 屏幕画面）→ 解决"______"（回扣痛点）。
> 第二步：______（操作 + 画面 + 真实步骤如授权）→ 解决"______"。
>   - 诚实边界：______（本地不上传/仅供参考/非诊断）。
> 第三步：______（操作 + 画面）→ 解决"______"。
> 持续使用：______（成长/反馈机制，7/14/30 天之类）。

### 2.3 副线功能（~25s）
> 引用扣题："______"。双方同意 → 能看见什么 → 边界（非监控/可解绑）。

### 2.4 底线与未来（守，~20s）
> 三条底线：①______ ②______ ③______；专业背书：______。
> 下一步（明确是规划）：接入______；异常时只提醒就医，不诊断、不处方、不替代检查。
> XX 负责______；医院负责______。

## 三、升华（0:XX–0:XX，约 20%）
> 我们解决的不是"______"，而是三个具体问题：
> ______、______、______（与第一段痛点逐一对应）。
> （可选）N 人 / N 天 / 从零做出______。
> 我们不______，也不______（边界表态）。
> 我们只想______（具体动作 + 情感结果）。
> 金句：让______，不再______。
> XX——______、______、______。（slogan 定格）
```

## 7. 交稿前自检清单（对照作文评分标准逐项打勾）

**审题扣题**
- [ ] 赛题原话/关键词在稿中出现 ≥3 次，且引用出处准确（不点未核实人名校名）。
- [ ] 中心论点一句话能说清，且在痛点段末尾亮明。

**结构（权重最高）**
- [ ] 严格三段顺序：痛点 → 过程 → 升华，无缺失、无调换。
- [ ] 时间/字数配比 ≈ 22% / 58% / 20%。
- [ ] 第二段是操作流（第一步/第二步/第三步），不是功能参数表。
- [ ] 每个功能点都完成"是什么→怎么用→解决哪个痛点"。

**内容与论证**
- [ ] 数据真实、与问卷后台一致；百分比优先，≤4 个。
- [ ] 至少 1 处对比论证、1 个具体生活切片、1 个专业背书。
- [ ] 规划功能全部用"下一步/未来"口径，无已上线包装。

**语言与情感**
- [ ] 开头 15 秒内有钩子；结尾有 ≤14 字金句且能做封底。
- [ ] 首尾呼应（开头埋的钩子结尾回收）；全篇有统一意象和情绪弧线。
- [ ] 通读计时达标（4 字/秒估算 + 停顿），超时按"先删未来枚举、再删副线修饰、不动痛点与金句"顺序砍。

**合规（思想健康线，一票否决）**
- [ ] 不诊断、不处方、不承诺疗效（无"治感冒/治 XX"）。
- [ ] 无手机号/未核实校名/第三方真实身份信息。
- [ ] 视频/隐私表述真实（本地识别、双方同意、可解绑）。

## 8. 版本缩放速查

| 时长 | 总字数 | 痛点 | 过程 | 升华 |
|---|---|---|---|---|
| 90 秒电梯版 | ~360 字 | 1 个切片 + 1 个数据 + 论点（~20s） | 只演核心闭环三步 + 一句底线（~55s） | 三问回收 + 金句（~15s） |
| 4 分钟标准 | ~900 字 | 五步法完整版（~55s） | 理念 + 三步 + 副线 + 底线（~2:20） | 四步收束（~40s） |
| 5–6 分钟加长 | ~1200–1400 字 | 痛点可加第二个切片（~1:10） | 三步各展开 + 演示停留 + 商业路径（~3:30） | 加团队故事一句，金句不变（~50s） |
