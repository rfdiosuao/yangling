# 养令 · 演示视频脚本与路演稿

2026-09-08 · 视频时长目标 3 分 30 秒（可裁成路演 4 分钟版）

> 用途一：提交材料 #4「产品演示」= 本视频（可运行原型 + 录屏 + 旁白）。
> 用途二：9/13 路演现场直接播放本视频 + 末尾 1 分钟问答预案，全程不依赖临场发挥。
>
> 设计原则：开场利他让评委一耳朵记住 → 真实证据让评委相信 → 演示让评委看懂 → 技术壁垒让评委认可 → 升华让评委想给高分。

---

## 0. 先定三件事（录制前必读）

1. **时长**：正片 3:30。路演当天如需更短，按第 2 条"精简版剪法"直接剪到 2:50。
2. **配音**：用现有豆包克隆音色（邻家男孩，语速 -12，音调 +2），温柔、不赶、有停顿。
3. **素材**：所有产品画面用真机录屏 + 服务器真实地址（https://yangling.entermodetwo.com），不用静态图充数。

**⚠️ 诚实红线（必须遵守）**：脚本中所有 `【填：…】` 处必须填入真实数据后才可定稿。问卷数据没回来前，宁可说"我们正在 20 多个养生群里收集反馈"，也不要编造数字。被评委追问截图时拿不出来 = 全盘崩。

## 1. 完整分镜脚本（3:30）

### 镜头 0 — 开场钩子（00:00–00:18）

| 项 | 内容 |
|---|---|
| 画面 | 黑底渐亮 → 一位长辈在晨光里练八段锦的剪影（侧后方），画面安静、有鸟鸣 |
| 字幕 | "练完八段锦，我爸总会问一句——我练得对吗？" |
| 旁白 | 很多长辈退休后开始练八段锦、太极、易筋经。但练完，他们常常只问自己一个问题：我练得对不对？ |
| 剪辑提示 | 前 6 秒只有画面和鸟鸣，不开口，制造情绪留白 |

### 镜头 1 — 痛点（00:18–00:55）

| 项 | 内容 |
|---|---|
| 画面 | 快切 3 张手机录屏（或实拍）：长辈对着视频比划 / 膝盖不舒服皱眉 / 坚持几天就断掉 |
| 字幕 | 三个痛点：动作没人纠正 · 坚持不下来 · 知识真假难辨 |
| 旁白 | 动作对不对，没人告诉他们；练几天就断了，没人提醒他们；网上说啥的都有，不知道该信谁。 |
| 旁白续 | 我们走访了【填：N】个太极、八段锦、广场舞、养生群，收回【填：M】份问卷。练功的人里，【填：X%】说"练完不知道动作标不标准"，【填：Y%】说"坚持不下来、想不起来练"。 |
| 剪辑提示 | 此段配问卷截图 2 张（群名称打码），只给关键数字，别放一堆饼图 |

### 镜头 2 — 方案亮相（00:55–01:20）

| 项 | 内容 |
|---|---|
| 画面 | 手机主屏"养令"图标点开 → 首页（东方美学，暖米金） |
| 字幕 | "养令：懂中国人身体节律的 AI 养生搭子" |
| 旁白 | 所以我们做了养令——一个懂中国人身体节律的 AI 养生搭子。它不看病、不卖药，只做一件事：帮你把养生，练对、练开心。 |
| 剪辑提示 | 首屏画面停留 3 秒再动，让评委看清界面气质 |

### 镜头 3 — 说状态 → 得方案（01:20–01:50）

| 项 | 内容 |
|---|---|
| 画面 | 输入框输入："昨晚三点睡，嘴苦，今天下午要讲一下午会" → 生成今日养生时序卡 |
| 字幕 | "一杯 · 一动 · 一息" |
| 旁白 | 你只需要说一句今天的状态。养令结合二十四节气、时辰和体质，给你生成今天的三件事：一杯——应季的食疗方；一动——导引拉伸或穴位按摩；一息——一段呼吸或作息建议。 |
| 剪辑提示 | 字幕跟随三张卡片出现，节奏与旁白对齐 |

### 镜头 4 — 动作识别（01:50–02:15）

| 项 | 内容 |
|---|---|
| 画面 | 切到"动作识别"：真人在手机前练八段锦起势 / 肩颈拉伸，画面出现骨骼关键点，达标时提示 + 开花 |
| 字幕 | "AI 看得懂你的动作" |
| 旁白 | 动作环节，AI 真的在看。摄像头识别你的骨骼关键点，练到位，屏幕上开出一朵小花。练得不对，它轻声告诉你哪里偏了。 |
| 剪辑提示 | 这段是记忆点，用真实演示录屏，允许有一秒的"真人入镜"感 |

### 镜头 5 — 知识问答有据可依（02:15–02:40）

| 项 | 内容 |
|---|---|
| 画面 | 问答页输入："白露之后适合喝什么？" → 回答底部出现引用标记 [1][2]，来源可点开 |
| 字幕 | "每个回答，都有出处" |
| 旁白 | 关于养生知识，养令不靠 AI 编。我们的知识库里有【填：86】篇中医学术论文、节气文献和权威资料，每一个回答都带来源编号，点开就能看到出处。 |
| 剪辑提示 | 引用角标做高亮动画，强调"有据可依" |

### 镜头 6 — 主动提醒（02:40–03:00）

| 项 | 内容 |
|---|---|
| 画面 | 手机锁屏 / 通知栏弹出："老王，喝点水吧"，用户轻点 → App 打开对应页面 |
| 字幕 | "到点，叫醒你照顾自己" |
| 旁白 | 它还会主动提醒你。装成 App 后，养令按你的作息定时提醒喝水、起身、舒展肩颈——提醒不会只说一句"该养生了"，而是知道你在哪一步，把你带到对应的那一件事上。 |
| 剪辑提示 | 这里展示 Android 真机通知实拍，是"真的能动"的证据 |

### 镜头 7 — 技术壁垒（03:00–03:18）

| 项 | 内容 |
|---|---|
| 画面 | 架构图快闪：节气×时辰×体质 知识库 → 规则引擎兜底 → LLM 只做表达 → RAG 引用 |
| 字幕 | "规则兜底，AI 不胡说" |
| 旁白 | 技术上，我们做了两道保险：养生建议由结构化的知识库和规则引擎生成，AI 大模型只负责把方案说得更贴心，不能自由发挥；所有回答必须引用知识库依据，找不到依据就明说不知道。 |
| 剪辑提示 | 用一屏架构图，2-3 秒，别逐字念 |

### 镜头 8 — 升华（03:18–03:28）

| 项 | 内容 |

## 2. 精简版剪法（路演 2:50 备用）

现场如果被要求压缩，按此删：

- 镜头 1 旁白数字部分压成一句"问卷里 6 成的人说不知道动作标不标准"
- 镜头 5（问答）缩到 10 秒，只留引用角标动画
- 镜头 6（提醒）缩到 8 秒
- 镜头 8 和 9 合并

即：开场钩子 → 痛点一句带过 → 说状态得方案 → 动作开花（核心记忆点） → 技术兜底 → 升华收尾。

## 3. 一分钟问答预案（路演现场）

| 可能被问 | 标准回答 |
|---|---|
| 养生建议的科学性谁负责？ | 只取国标《中医体质分类与判定》+ 公开文献，知识库全部标注来源；我们定位是生活方式干预，不做诊断，页面明确写了"不适请就医"的边界。 |
| 和市面养生 App 有什么区别？ | 它们要么是打卡日历，要么是聊天机器人。我们有三个不一样：动作真的看得懂（骨骼识别）；回答必须有依据（RAG 引用）；到点真的会提醒你。 |
| 数据安全？ | 状态数据本地存储，上传走 HTTPS 去标识化；不采集病历、不做诊断，涉及健康风险一定引导就医。 |
| 商业上怎么用？ | 面向慢病管理、药企/健康管理机构、社区养老场景；本次聚焦华润三九"现代养生"命题，A 类场景直接对口。 |
| 为什么用大模型？ | 规则引擎保证正确性，大模型只做表达润色——正确性不受模型发挥影响，这是架构上最稳的一点。 |
