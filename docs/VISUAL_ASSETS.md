# 🎨 养令 YangLing · 视觉资产需求清单

> **用途**:供生成背景图、穴位图、图标等素材。按优先级(P0 必须 / P1 重要 / P2 加分)生成。
> **统一风格**:东方美学 · 米白宣纸底 + 墨色 + 随节气变的主色 + 流体呼吸感(详见 02-assets/UI_AESTHETICS.md)。
> **输出要求**:PNG,透明背景(背景图除外),≥1024px,命名 `snake_case.png`。

---

## P0 · 必须(主链路演示要用)

### 1. 流体呼吸背景(首页主视觉锚点)
- **用途**:养令首页背景,「会呼吸的东方时令历」,鼠标移动时墨色光斑流动晕染(复用 HERO_FLUID_MOTION 动效思路)。
- **生成建议**:
  - 深色宣纸底 + 水墨色 + 一个节气主色(当前白露=秋金,偏暖米金)的光斑
  - 要有"呼吸感":光晕随节奏开合(可用两层:静态宣纸底 + 动态光斑 canvas)
- **文件**:`bg/breath_ink.png`(静态底图,动态光斑用 CSS/canvas 实现)
- **尺寸**:1920×1080

### 2. 今日时序卡 · 卡片底图(3 类)
- **用途**:M3 时序卡的「一杯/一动/一息」三种卡片背景,让卡片有质感。
- **生成建议**:
  - 一杯:淡米色底 + 一杯热气袅袅的茶/汤碗水彩
  - 一动:淡米色底 + 经络穴位线稿(局部)
  - 一息:淡米色底 + 涟漪/呼吸波纹
- **文件**:`bg/card_cup.png` `bg/card_move.png` `bg/card_breath.png`
- **尺寸**:800×400

### 3. 穴位图(先做 3 个 demo 穴位)
- **用途**:M4 动作演示,点开穴位显示位置 + 跟做动画。
- **生成建议**:人体线稿(正面/背面) + 穴位红点高亮,穴位位置用箭头/标注。
- **文件**:`acupoints/body_front.png` `acupoints/body_back.png`(人体线稿,穴位点可用 CSS 定位叠加)
- **尺寸**:600×1200(竖版半身)

---

## P1 · 重要(提升完成度)

### 4. 节气视觉(先做当前节气 白露 + 秋季)
- **用途**:首页节气流转动画/时序卡头部,随节气变色。
- **生成建议**:白露 = 秋金/暖米,画面有露珠、芦苇、月白意象。
- **文件**:`bg/solar_bailu.png`(白露),`bg/solar_autumn.png`(秋季通用)
- **尺寸**:1920×1080

### 5. 首页 Hero 视觉
- **用途**:首页首屏大图,30 秒法则的主视觉锚点。
- **生成建议**:一幅"东方时令历"意境图——宣纸 + 墨色山水 + 一个发光的节气印章(可加中文"养令"竖排 + 英文 `YANGLING` 装饰)。
- **文件**:`bg/hero_yangling.png`
- **尺寸**:1920×1080

### 6. 图标集(一套 12 个)
- **用途**:导航/卡片/日历图标。
- **生成建议**:线性墨色风格,圆角,统一线宽;包括:对话、时序卡、日历、家庭、睡眠、打卡、分享、体质、节气、穴位、呼吸、设置。
- **文件**:`icons/icon_*.png`(或直接给 SVG 更佳)
- **尺寸**:64×64(SVG 更佳)

## P2 · 加分(有余力再做)

- **用途**:M6 给爸妈版,大字号、高对比、口语化。
- **生成建议**:更朴素、更大留白的米白卡片,无复杂纹理,适合大字号阅读。
- **文件**:`bg/family_card.png`
- **尺寸**:800×400

- **用途**:M7 睡前放松背景,跟随呼吸的流体。
- **生成建议**:深蓝紫夜空 + 缓慢流动的星尘/涟漪,柔和不刺眼。
- **文件**:`bg/sleep_night.png`
- **尺寸**:1920×1080

### 9. 分享卡片模板
- **用途**:打卡后生成可分享的"今日养生卡"(社交传播,评委可分享)。
- **生成建议**:米白 + 墨色 + 节气主色的"今日养生"竖版卡片模板,留出文字区。
- **文件**:`bg/share_card.png`
- **尺寸**:1080×1440(竖版 3:4)
