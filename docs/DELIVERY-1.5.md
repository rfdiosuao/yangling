# 养令 1.5.0 最小功能补全

日期：2026-09-10。

## 本次实现

- 首页“查看成长与家人”入口；长期本机打卡日历、连续天数、累计天数、三项全完成天数；迁移已有当天记录，重复打卡不重复计数。
- 累计 7 / 14 / 30 天解锁新芽、花芽、开花，中断不退级；里程碑文字提醒。
- 小芽新增三张生成图片，待机随成长阶段变化；开心与休息继续复用已有图片，保留拖动、点击、收起和录音鼓励。
- 家庭邀请码、双方确认、每日完成摘要、快捷鼓励、自定义留言、未读/已读、解绑。自有服务保存关系，打开家庭页面获取消息，前台每 30 秒刷新。
- 原“一动”手绘图标替换为已生成图片；Android 版本为 1.5.0 / code 7。

## 使用方法与边界

完成任意一项算一个陪伴日，三项都完成另计完整养生日。首页点击成长入口可以查看历史，切换“家庭陪伴”输入昵称，生成邀请码发给家人。家人申请后，发起人刷新并确认即可共享。

不接第三方推送；个人定时提醒仍走安卓本地通知。家庭留言不是关掉 App 后立即弹出的系统通知。打卡历史与设备令牌在本机，清除应用数据后需要重新绑定；本轮不做云端账号恢复。

成长日历保留在本机，家庭只同步当天摘要，不上传问答、身体状态输入或摄像头内容。解绑删除对应关系和留言。
